# Приложение «EDOG видео» для Android

Видео с камеры собаки (XIAO ESP32-S3 Sense): кадр вписывается в экран с сохранением пропорций, поворот экрана поддерживается.

- **Поверх видео — что видит собака:** рамки людей с подписью «человек 87% · 1,4 м», пунктир границы свободного пола с расстояниями, состояние патруля и «близко: 0,42». Всё подписано текстом. Данные берутся из заголовков кадров (`X-Detect`, `X-Free`, `X-Vision`, `X-Patrol`), см. [docs/patrol.md](../docs/patrol.md).
- **Радар — карта вокруг собаки** (`X-Map`): в портретной ориентации под видео, в альбомной справа. Со старой прошивкой без карты радара нет.

- **Кнопка патруля** (слева сверху): «Запустить патруль» / «Остановить патруль», шлёт `POST /api/patrol` как кнопка портала; итог показывается всплывающей подписью.
- **Кнопка стойки** (под кнопкой патруля): по нажатию переключает базовую стойку и базовую на стопперах (`POST /api/gait`), на кнопке написано, какая сейчас.
- Собака ищется по адресу `edog.local:8080`; другой адрес (IP) задаётся кнопкой «Адрес».
- Видео у собаки одно на всех. Если его уже смотрит другое устройство (портал или другой телефон), приложение спрашивает, переключить ли видео сюда. Если отказаться, на экране остаётся кнопка «Переключить сюда».
- Когда приложение свёрнуто, видео не держится, и его может забрать другое устройство.

## Сборка

Нужны JDK 17+ и Android SDK (платформа 35); путь к SDK — в `ANDROID_HOME` или в `local.properties` (`sdk.dir=...`).

```
cd android
gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. Поставить на телефон по USB: `adb install -r app/build/outputs/apk/debug/app-debug.apk` или скопировать файл на телефон и открыть.
