# Edog

Робопёс на 3D-печати с управлением с Raspberry Pi.

## Структура проекта

```
cad/
  origin/        — оригинальные STL автора базовой модели (для справки, не редактируем)
  origin_fixes/  — исправленная геометрия оригинала (напр. fixed_motor_bloc.stl)
  freecad/       — рабочие исходники FreeCAD (.FCStd): кастомный корпус + платформа под RPi + стандартные боковые рамы
  custom/        — финальные STL для печати, нарезанные из freecad/ (магнитные крепления корпуса и платформы)
firmware/      — управляющий код для Raspberry Pi
docs/          — обсуждение идей, решения, заметки по железу
```

## О проекте и железе

См. [docs/project.md](docs/project.md) и [docs/hardware.md](docs/hardware.md).

## CAD

Основной рабочий файл: `cad/freecad/body_magnets.FCStd` — кастомное тело, кастомная площадка под RPi и стандартные боковые рамы в одной сборке. Из него нарезаются STL в `cad/export/`.
